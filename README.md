# PlantGuard AI

**Мобильный ассистент для экспресс-диагностики здоровья растений.**

PlantGuard AI — мобильное приложение для предварительной оценки состояния растений по фотографиям листьев. Приложение включает пошаговый процесс фотофиксации, наглядное структурированное отображение результатов анализа, практические агрономические рекомендации по уходу и сохранение истории проверок.

Приложение оптимизировано для анализа листьев томатов и других сельскохозяйственных культур и разработано на базе Expo, React Native, TypeScript и Expo Router.

> **Статус проекта:** MVP / Функциональный прототип. Доступность анализа и точность диагностики зависят от подключенного провайдера и выбранного режима работы. Демонстрационные сценарии не являются реальными медицинскими или фитосанитарными заключениями.

## Обзор

PlantGuard AI создан для того, чтобы сделать первичный фитосанитарный мониторинг простым и доступным прямо в поле или теплице. Пользователь делает снимок листа или выбирает фото из галереи устройства, проверяет кадр, запускает анализ и получает структурированный результат: предположительный диагноз, степень поражения, описание симптомов и рекомендуемые агротехнические шаги.

В приложении чётко разделены демонстрационные примеры и реальная диагностика. Если аналитический сервис не подключён, произвольным пользовательским фотографиям не присваиваются случайные вымышленные диагнозы или фальшивые проценты уверенности.

## Возможности

- **Пошаговая фотосъёмка** — съёмка на камеру с прицельной рамкой или выбор из галереи, подсказки по освещению, резкости и кадрированию.
- **Интерактивная диагностика** — наглядный процесс анализа и структурированная карточка результата.
- **Честный демо-режим** — подготовленные эталонные примеры наглядно отделены от результатов работы моделей.
- **Агрономические рекомендации** — безопасные биологические, санитарные и агротехнические меры с напоминанием о предварительном характере оценки.
- **История анализов** — локальное хранение, фильтрация по культурам и детальный просмотр прошлых проверок.
- **Каталог культур** — справочник поддерживаемых и планируемых сельскохозяйственных растений.
- **Мобильная навигация** — продуманная архитектура экранов на Expo Router с поддержкой жестов и плавных переходов.
- **Конфигурация провайдеров** — поддержка настройки различных провайдеров анализа через переменные окружения и интерфейс (Google Gemini, OpenRouter, локальный классификатор).

## Принципы достоверности диагностики

PlantGuard AI предназначен исключительно для предварительного скрининга и не заменяет лабораторный анализ или профессиональную консультацию дипломированного агронома.

Архитектура строится на трёх базовых принципах:

1. **Никаких выдуманных прогнозов.** Демонстрационные примеры никогда не выдаются за результат анализа произвольного снимка пользователя.
2. **Прозрачность и калибровка уверенности.** Вывод алгоритма не является абсолютным доказательством болезни. Результаты следует оценивать в совокупности с качеством фото, погодными условиями и полевым осмотром.
3. **Безопасность рекомендаций.** Советы по уходу ограничены базовыми агротехническими и биологическими мерами (стандарты FAO / IPM). Решения о применении химических средств защиты и расчёт дозировок пестицидов требуют очной оценки специалиста и строгого соблюдения регламентов производителя.

## Пользовательский сценарий

1. Запустите приложение и перейдите к экрану проверки растения.
2. Сделайте фотографию листа или выберите снимок из галереи.
3. Проверьте фото и укажите культуру (или оставьте автоматическое определение).
4. Запустите диагностику.
5. Изучите полученный диагноз, уверенность алгоритма, описание признаков и карту симптомов.
6. Ознакомьтесь с предложенными мерами предосторожности и рекомендациями.
7. Сохранённая запись всегда доступна для повторного просмотра во вкладке «История».

Точный результат зависит от того, работает ли приложение в автономном демо-режиме или с настроенным провайдером анализа.

## Начало работы

### Требования

- Node.js (LTS) и npm
- Git
- Android- или iOS-устройство, либо эмулятор
- Приложение Expo Go для быстрого тестирования на телефоне

### Установка

```bash
git clone https://github.com/ubatora07/plantguard.git
cd plantguard
npm install
```

### Запуск сервера разработки

```bash
npx expo start
```

После запуска используйте команды в консоли Expo:

- `a` — открыть на подключённом Android-устройстве или эмуляторе
- `w` — открыть в браузере (веб-версия)

Для тестирования на физическом телефоне отсканируйте отображаемый QR-код в приложении **Expo Go**.

## Настройка интеграций

Приложение поддерживает работу как в автономном режиме, так и с подключением внешних провайдеров (Google Gemini, OpenRouter).

Для локальной настройки создайте файл `.env` в корне проекта на основе примера:

```dotenv
EXPO_PUBLIC_DIAGNOSIS_MODE=demo

EXPO_PUBLIC_GOOGLE_API_KEY=
EXPO_PUBLIC_OPENROUTER_API_KEY=
EXPO_PUBLIC_OPENROUTER_MODEL=

EXPO_PUBLIC_API_BASE_URL=
```

Если ключи API не указаны, приложение автоматически переключается на встроенный автономный справочник и демонстрационные сценарии.

### Безопасность

Переменные с префиксом `EXPO_PUBLIC_` попадают в клиентский бандл приложения и не являются секретными.

Для промышленной эксплуатации рекомендуется маршрутизировать запросы через собственный защищённый backend-прокси, который хранит ключи на сервере, валидирует входящие запросы и контролирует лимиты.

Не сохраняйте приватные API-ключи в публичных репозиториях.

## Контроль качества

Проект покрыт автоматическими проверками:

```bash
npm run typecheck    # Проверка типов TypeScript (0 ошибок)
npm run lint         # Проверка линтером ESLint (0 ошибок)
npm test             # Запуск тестов Jest (19 сьютов, 112 тестов)
npx expo-doctor      # Проверка здоровья конфигурации Expo
npx expo export      # Тестовая компиляция релизных бандлов
```

Рекомендуется запускать проверки перед отправкой изменений.

```bash

```

## Текущие рамки и ограничения

- Основной протестированный фокус приложения — диагностика заболеваний листьев томатов и картофеля.
- Демонстрационные сценарии носят иллюстративный характер и показывают поведение интерфейса.
- Диагностика по фото не заменяет лабораторные агрохимические и бактериологические исследования.
- Точность классификации зависит от освещения, фокуса, чистоты поверхности листа и наличия артефактов съёмки.
