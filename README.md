# PlantGuard AI — Мобильный помощник для диагностики растений

Полноценный MVP мобильного приложения для предварительного экспресс-распознавания болезней томатов по фотографии листьев, построенный на стеке **Expo SDK 57**, **React Native 0.86**, **TypeScript** и **Expo Router**.

Приложение строго следует **принципу честной диагностики**:
- **Честный DEMO-режим**: в демонстрационном режиме представлены реальные обучающие сценарии (`Alternaria solani`, `Phytophthora infestans`, «Здоровый лист», «Недостаточно данных»). 
- **Произвольные фотографии**: если пользователь загружает собственное фото в DEMO-режиме, приложение честно показывает его и открыто сообщает статус «Модель не подключена», **не приписывая снимку случайных или выдуманных диагнозов и фальшивых процентов уверенности**.
- **Безопасность рекомендаций**: рекомендации содержат только безопасные агротехнические меры (удаление поражённых листьев, вентиляция, прекращение верхнего полива, обращение к агроному). Запрещены автоматические назначения пестицидов и опасных дозировок.

## 🤖 Запуск на Android и сборка APK / AAB

### Вариант 1: Через Expo Go (быстрый старт на телефоне)
1. Установите **Expo Go** из Google Play Store на Android-устройство.
2. Подключите компьютер и телефон к одной Wi-Fi сети (или используйте режим туннеля: `npx expo start --tunnel`).
3. Запустите проект: `npx expo start`.
4. Отсканируйте отображаемый QR-код камерой приложения Expo Go.

### Вариант 2: Запуск в Android Emulator
1. Запустите эмулятор в Android Studio.
2. Выполните:
   ```bash
   npm run android
   ```

### Вариант 3: Сборка автономного APK / AAB (EAS Build)
Для сборки готового установочного файла `.apk` для тестирования или `.aab` для публикации в Google Play:
1. Установите EAS CLI:
   ```bash
   npm install -g eas-cli
   ```
2. Авторизуйтесь в аккаунте Expo:
   ```bash
   eas login
   ```
3. Сконфигурируйте сборку:
   ```bash
   eas build:configure
   ```
4. Соберите standalone APK для Android:
   ```bash
   eas build --platform android --profile preview
   ```

## 🔌 Подключение реальных ML-моделей (Gemini / OpenRouter)

Приложение умеет работать с реальными vision-моделями "из коробки", передавая им фото напрямую.

### 1. Настройка переменных окружения
В корне проекта создайте или отредактируйте файл `.env`:
\`\`\`env
# Включает реальный AI-анализ
EXPO_PUBLIC_DIAGNOSIS_MODE=ai

# [Вариант 1] API-ключ Google Gemini (рекомендуется)
EXPO_PUBLIC_GOOGLE_API_KEY=your_gemini_api_key

# [Вариант 2] API-ключ OpenRouter (будет использоваться как запасной или основной, если нет Gemini)
EXPO_PUBLIC_OPENROUTER_API_KEY=your_openrouter_key
# Опционально: модель OpenRouter (по умолчанию бесплатная google/gemini-2.0-flash-lite-preview-02-05:free)
EXPO_PUBLIC_OPENROUTER_MODEL=your_preferred_model

# [Вариант 3] Кастомный бекенд (устаревший/резервный способ)
EXPO_PUBLIC_API_BASE_URL=https://your-ml-api.plantguard.ai
\`\`\`

> **Конфигурация:** Для локальной разработки и тестирования ключи указываются в файле `.env`. В продакшн-окружении запросы маршрутизируются через защищённый backend-прокси.

### 2. Как это работает
При использовании облачных мультимодальных провайдеров (Gemini / OpenRouter):
- Изображение **оптимизируется и сжимается на устройстве** перед отправкой (макс 768px, JPEG 70%) — размер не более 60–100 КБ, что обеспечивает быструю работу даже при слабом полевом 3G/4G интернете.
- Система использует валидированный протокол фитосанитарной диагностики для выдачи строго типизированного JSON.
- `AutoAiProvider` выполняет умную маршрутизацию между персональными ключами, быстрыми моделями и локальным классификатором.
- Если ключи не настроены или отсутствует интернет — приложение работает в автономном режиме со встроенной базой знаний.
